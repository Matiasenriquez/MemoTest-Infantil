# 🧠 MemoTest Infantil

MemoTest Infantil es un juego de memoria diseñado para niños de entre **5 y 10 años**, cuyo objetivo es estimular la concentración, la memoria visual y la atención de una forma divertida e interactiva.

El proyecto fue desarrollado utilizando tecnologías web sin frameworks, lo que permite ejecutarlo directamente desde cualquier navegador moderno.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* Tailwind CSS
* JavaScript (Vanilla)

## 📥 Instalación

No es necesario instalar programas adicionales ni dependencias para ejecutar el proyecto.

### Opción 1: Descargar desde GitHub

1. Ingresar a este repositorio.
2. Hacer clic en el botón **`<> Code`**.
3. Seleccionar la opción **`Download ZIP`**.
4. Una vez descargado el archivo, extraer su contenido en la ubicación deseada.

### Opción 2: Clonar el repositorio

```bash
git clone https://github.com/Matiasenriquez/MemoTest-Infantil.git
```

## ▶️ Ejecución

1. Abrir la carpeta del proyecto.
2. Localizar el archivo **`index.html`**.
3. Hacer doble clic sobre el archivo o abrirlo con cualquier navegador web.

El juego se ejecutará inmediatamente, sin necesidad de realizar configuraciones adicionales.

## 🎯 Objetivo del juego

El jugador deberá encontrar todas las parejas de cartas iguales utilizando la menor cantidad de intentos posible, ejercitando la memoria y la capacidad de observación.
